# Z-Bot Reads

Build a Telegram book search bot for Vercel with start, button navigation, search, paginated results, book details, and source links, plus a modular BookProvider with mock data so the flow works end to end. Then, connect the real Z-Library backend later.

This project was built with [Lovable](https://lovable.dev).
